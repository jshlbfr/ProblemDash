ProblemDash
- A full-stack web application for tracking coding problems and progress.

Tech Stack:

Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

Backend
- Node.js
- Express
- PostgreSQL
- Prisma
- Supabase
  
Features
- Add coding problems
- View problems
- Edit and delete problems
- Track difficulty and status
- View dashboard statistics

Status:

🚧 Currently in development.
